# РАДИУС — шинный сервис

Статический лендинг на HTML, CSS и JavaScript. Главная страница находится в корне репозитория в `index.html`.

## GitHub Pages

Файл `.github/workflows/deploy.yml` автоматически публикует сайт на GitHub Pages после каждого push в `main`. В настройках репозитория в **Settings → Pages** источник публикации должен быть **GitHub Actions**.

## Настройки сайта

- Примерные цены и адрес отправки формы настраиваются в `main.js`.
- Перед приёмом заявок заполните `FORM_ENDPOINT` в `main.js`.
- Фото баннера загружается с Unsplash; для него требуется интернет.
